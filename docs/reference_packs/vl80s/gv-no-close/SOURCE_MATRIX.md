## Подтвержденные смысловые разделения

1. **ГВ не пытается включиться** — ветвь включающей команды/разрешающих условий.
2. **ГВ включается и сразу отключается** — удерживающая цепь и/или защита.
3. **ГВ отключается позже под нагрузкой** — защита/нагрузка/удержание; не следует смешивать с первоначальным отказом включения.
4. **Одна секция vs все секции** — только изменение приоритета локальной/общей ветви, не диагноз.

## Открытые вопросы

- Найти первичное заводское руководство по конкретным исполнениям ВОВ-25, применявшимся на ВЛ80С.
- Подтвердить из первичного документа точные условия/порог давления для каждого исполнения аппарата и точку измерения.
- Привязать серийные изменения цепей управления ГВ к конкретным диапазонам номеров только после первичной схемной проверки.

## Restricted material

Источники S05/S06/S10 содержат нештатные методы восстановления цепей. В pack сохранены только факт существования, назначение затронутого участка и происхождение. Пошаговые перемычки и принудительные действия в unrestricted payload не перенесены.
