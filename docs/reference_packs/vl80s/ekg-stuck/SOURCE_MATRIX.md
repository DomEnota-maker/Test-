# Source Matrix — `ekg-stuck`

Сценарий: **ВЛ80С — ЭКГ не набирает, не сбрасывает или остановился между позициями**.

## Сильные разделения для будущего графа

1. `КМЭ дал команду` ≠ `ЭКГ реально переместился`.
2. `Указатель показывает позицию` ≠ безусловное доказательство состояния всех контактов ЭКГ.
3. `Не движется` ≠ `остановился между позициями` ≠ `идет непрерывно` ≠ `рассинхронизировался`.
4. Отказ одной секции и остановка всех секций требуют учета схемы синхронизации.
5. Автоматический непрерывный ход имеет несколько известных направлений поиска; один симптом не подтверждает контактор 208 или сервомотор как причину.

## Подтвержденная вариантность

Исторический технический источник подтверждает изменение цепи синхронизации **с №1406** для предотвращения рассинхронизации ЭКГ-8Ж. Это хранится как исторический/profile факт, а не как второй сценарий.

Вторичные источники сообщают и о более поздней серийной границе. До нахождения первичной схемы/ведомости изменений она остается `UNVERIFIED` и не используется в runtime gate.

## Maintenance boundary

Каталог ПКБ ЦТ указывает действующую документацию `ПКБ ЦТ.25.0072` по ТО и текущему ремонту ЭКГ-8Ж. Поэтому численные ремонтные нормы и внутренние ремонтные операции должны поступать из этого слоя/документа, а не из эксплуатационных статей.

## Restricted material

Старые эксплуатационные документы содержат перемычки, принудительное воздействие на реле/контакторы и способы изменения штатной логики управления. В unrestricted pack пошаговые процедуры намеренно отсутствуют. Сохраняются только происхождение, факт применения и затрагиваемая функция.
