## Подтвержденные смысловые разделения

1. **ЭКГ не перемещается** — маршрутизация в отдельный канонический сценарий `ekg-stuck`, а не объявление отказа ЛК.
2. **ЭКГ перемещается, а тяги нет** — повышается приоритет цепи ЛК/силовой ветви после ЭКГ.
3. **Все секции / одна секция / одна группа / один ЛК** — разные масштабы локализации, но не готовые диагнозы.
4. **ЛК отпали в работе** — до повторного штатного сбора важно фактическое состояние ЭКГ, в том числе возврат к нулю.

## Открытые вопросы

- Найти первичный источник по серийным изменениям цепи ЛК, включая ввод ПВУ1 и точные границы применимости.
- Для старых режимов движения на 6/7 ТЭД найти актуальный нормативный/локальный документ или окончательно оставить их только в архивном слое.
- Найти первичный ремонтный документ для ПК-356, если численные ремонтные нормы будут нужны в Detailed/Learning.

## Restricted material

Старые источники описывают прямое питание и перемычки в цепях ЛК. В unrestricted pack сохраняются только существование практики, затрагиваемые узлы и provenance. Пошаговые действия не включены.
