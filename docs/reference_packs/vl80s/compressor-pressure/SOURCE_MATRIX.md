## Ключевое диагностическое разделение

1. **Двигатель не запускается** → управление/контактор/защита/питание получают приоритет.
2. **Двигатель работает, давление растёт медленно** → производительность компрессора и утечка остаются альтернативами.
3. **После остановки давление быстро падает** → выше приоритет герметичности, обратной арматуры и потребителей.
4. **Тяжёлый запуск** → разгрузка 246 — только одна из возможных ветвей, не готовый диагноз.
5. **Стук/дым/перегрев/масло** → safety-приоритет выше измерительного эксперимента.

## Численные нормы

Старая инструкция ЦТ-ЦВ-ЦЛ-ВНИИЖТ/277 действительно содержала для ВЛ80 всех индексов с КТ6эл и объёмом ГР 1800 л значение **не более 45 с при наполнении 7,0→8,0 кгс/см²**. Оно сохранено только в `HISTORICAL`.

Инструкция РЖД №3508/р содержит регулировочные значения для регуляторов давления в ремонтном контексте. Они не должны автоматически становиться универсальным runtime-порогом ВЛ80С без подтверждения фактически установленного регулятора и применимости пункта.

## Restricted material

Старые локальные инструкции описывают принудительное питание/фиксацию реле и контактора мотор-компрессора, а также обход автоматики. В unrestricted pack пошаговые схемы и перемычки отсутствуют; сохраняются только факт, назначение, затрагиваемые аппараты и provenance.
