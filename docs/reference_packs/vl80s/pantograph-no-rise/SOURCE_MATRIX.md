# Source Matrix — ВЛ80С / `pantograph-no-rise`

## Шкала источников

- **A** — норматив/официальное правило безопасности; перед production обязательно проверить действующую редакцию.
- **B** — профильное техническое/учебное издание или руководство с известной библиографией.
- **C** — профессиональный эксплуатационный/ремонтный материал, репринт или публичная копия отраслевого материала.
- **D** — вторичный/сообщественный ресурс; только гипотеза, вариантный маркер или перекрёстная проверка.

Ни один источник C/D сам по себе не переводит нештатный приём в `ACTIONABLE`.

## Осознанно не заполненная категория `MANUFACTURER`

В этой исследовательской сессии не получена первичная заводская документация НЭВЗ/паспорт Л-13У1 с достаточной проверяемой идентичностью именно нужному исполнению ВЛ80С. Поэтому пакет **не маскирует учебную книгу под заводской источник**.

До получения такого источника `MANUFACTURER` в coverage matrix должен считаться `PENDING_PRIMARY_SOURCE`, а не заполняться догадкой.

## Ключевые cross-check группы

### 1. Подъём: механика + пневматика

`S02 + S04` независимо описывают пневматический привод и механическую работу токоприёмника.

### 2. Цепь управления 245 / 248 / блокировки

`S03 + S06 + S08` дают согласованную картину разделения электрической команды, разрешающих условий и пневматического исполнительного звена.

### 3. Ремонтная практика

`S05` используется отдельно от маршрутной диагностики: это источник о том, **что контролируют при ТО/ТР**, а не автоматическая команда локомотивной бригаде выполнять ремонт в пути.

### 4. Полевая практика

`S07 + S08` подтверждают существование нештатных обходов в эксплуатационных материалах. Сам факт существования можно хранить как знание, но procedure payload остаётся `RESTRICTED` и в эталонном пакете не воспроизводится.

### 5. Конфликт/неоднозначность давления

Разные материалы приводят значения давления для разных точек и условий (цилиндр/цепь управления/резервуар ГВ/условие проверки). Пакет **не сводит их в одно «универсальное давление подъёма»**. Это отдельный conflict case для Quality Control.

## Что требуется перепроверить перед production

1. Действительность и редакции нормативных документов.
2. Первичную заводскую документацию на токоприёмник/электросхему конкретного исполнения.
3. Серийные границы модернизаций (в частности упоминаемая граница около №631).
4. Точную точку измерения для каждого значения давления.
5. Применимость полевых материалов к конкретному локомотиву/депо/периоду.
